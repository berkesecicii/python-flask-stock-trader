# Stock Trading Web Application

A full-stack web application built with **Python**, **Flask**, and **SQL** that allows users to manage portfolios of stocks, simulating real-time buying and selling. This project was developed as part of Harvard University's CS50x curriculum.

### 🚀 Key Features
*   **User Authentication:** Secure user registration, login, and session management using hashed passwords.
*   **Real-Time Data:** Integrates with a third-party REST API to fetch live stock quotes and market data.
*   **Portfolio Management:** Dynamically calculates and displays users' current cash balances, stock holdings, and total portfolio valuation.
*   **Transaction History:** Logs all buy and sell transactions into a relational database for accurate record-keeping.
*   **Dynamic UI:** Uses Jinja2 templating and Bootstrap to render responsive, data-driven HTML views.

### 💻 Technology Stack
*   **Back-End:** Python, Flask, RESTful APIs
*   **Database:** SQLite, SQL
*   **Front-End:** HTML, CSS, Bootstrap, Jinja2
